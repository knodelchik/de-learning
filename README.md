# de-learning: дата інженерія для фулстака

**Відкрити курс:** https://knodelchik.github.io/de-learning/ (нічого не треба встановлювати)

Особистий курс: від «що таке ETL» до першого кейсу в портфоліо.
Темп: 8–10 год/тиждень, ~6 тижнів. Усі завдання складаються в один наскрізний проєкт
на даних вигаданого інтернет-магазину **«Комора»** (кава, чай, посуд, техніка).

## Старт

```bash
uv run scripts/generate_data.py                 # згенерувати data/raw/*.csv (один раз)
uv run scripts/sql.py "select * from orders limit 5"
uv run scripts/sql.py weeks/01-sql/solutions/task01.sql
```

Таблиці: `customers`, `products`, `orders`, `order_items`, `payments`.
Дані навмисно брудні, як у житті. Знайти пастки — це частина завдань.

## Інтерфейс

Те саме, але в браузері: урок, завдання, редактор SQL (DuckDB-WASM), автоперевірка.

```bash
uv run scripts/export_web_data.py               # один раз: CSV -> web/public/data/*.parquet
cd web && npm install && npm run dev
```

## Правила роботи з нейронкою

Писати код через нейронку — нормально, так зараз працюють усі. Але як дата інженер ти
відповідаєш за **правильність цифр**, а неправильні цифри не падають з помилкою:
дашборд просто тихо бреше клієнту. Тому:

1. **SQL на тижнях 1–2 пишеш руками.** Нейронці можна задавати питання на кшталт «чому
   це не працює» або «поясни window function», але не «напиши запит». SQL — це мова,
   якою ти потім читатимеш і перевірятимеш усе, що згенерує нейронка.
2. **Спочатку рішення, потім генерація.** Перед кожним завданням з тижня 3 запиши в
   `DECISIONS.md` своїми словами: що робимо, який grain, як забезпечуєш ідемпотентність.
   Нейронка реалізує *твоє* рішення, а не вигадує власне.
3. **Перевіряй цифри.** Кожну вітрину звір із сирими даними хоча б одним незалежним
   запитом (наприклад, сума виручки у вітрині = сума в raw після фільтрів).
4. **Рев'ю без нейронки.** Коли здаєш завдання, я ставлю питання по коду. Відповідаєш
   сам. Якщо не можеш пояснити рядок — значить ти його не розумієш, і тоді переробляємо.
5. **«Злам».** Періодично я навмисно ламатиму твій пайплайн, а ти шукаєш причину.
   Саме цим ти займатимешся на реальних проєктах.
